🛡️ Positive Pay Built — delivery to NewFirst pending

Check-fraud protection. Every time we cut checks for a community, we send the bank the list of checks we actually issued. The bank pays only those, and flags anything that does not match, before the money leaves the account.

How it works

01 / ISSUE
We cut the checks
Checks print from the community's account through the check register, each with its number, payee, and amount.
02 / SEND
We send the issued-check file
A Positive Pay file (check number, amount, date, payee, account) goes to the bank the same day, before any check clears.
03 / MATCH
The bank pays only matches
Any presented check that does not match the file — wrong amount, unknown number, altered payee — is held and flagged for review.
