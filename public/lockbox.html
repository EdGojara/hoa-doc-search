Status: the coupon generation (step 1) and the ledger posting engine (step 4) are live today. The middle — parsing NewFirst's Lockbox file and matching each line to a property — maps the moment they send their first test file. We build the parser to their real format rather than guess at it, so it can't break on the first live file. (This is the same self-serve import pattern used for Vantaca and bank statements: the file's columns are shown, and any unmatched line is queued for review, never posted blind.)

The coupon scanline

Every statement carries a machine-readable line NewFirst's scanner reads — this is what ties a mailed check back to the right owner automatically.
⑈ 000123456 ⑈   0004250 ⑆   WATERVIEW-001482 ⑆
Reads as: account 000123456 · amount due $42.50 · property reference WATERVIEW-001482. The property reference is what we match on in step 3 — it is the canonical property id, so there's no name-matching guesswork. Final scanline layout confirms with NewFirst's spec.
